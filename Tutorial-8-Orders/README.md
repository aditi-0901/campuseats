# Tutorial 8 – Orders Service

## Description

A RESTful Orders Service developed as part of the Web Services course. The project demonstrates backend development, REST API implementation, and CRUD operations using Node.js and Express.js.

## Features

- Create new orders.
- View all orders.
- View individual orders.
- Update existing orders.
- Delete orders.
- User-friendly frontend interface.

## Technologies Used

- Node.js
- Express.js
- HTML5
- CSS3
- JavaScript
- REST API
- JSON

## Installation

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   ```bash
   npm install
   ```

## How to Run

Start the server:

```bash
node server.js
```

Open the application in your browser:

```text
http://localhost:3000
```
